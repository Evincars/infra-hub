# Mise: Vysvětlit Service Watcher juniorním vývojářům

## Proč

Chci na skutečném kódu tohoto projektu učit juniorní vývojáře, jak funguje Java
a Spring Boot. Potřebuji umět vysvětlit jednotlivé pojmy, jejich použití a časté
chyby, ne pouze opakovat názvy anotací.

## Úspěch vypadá takto

- Vysvětlím rozdíl mezi Spring beanem, JPA entitou a repository.
- Ukážu tok požadavku od controlleru přes manager do databáze.
- Vysvětlím transakci, dirty checking a rozdíl mezi `@param` a `@Param`.
- Použiji krátké české lekce a tisknutelné taháky při výuce.

## Omezení

- Výuka i taháky jsou v češtině, identifikátory v kódu se nepřekládají.
- Příklady vycházejí z tohoto projektu a jeho skutečných verzí.
- Jedna lekce se soustředí na jeden malý koncept.

## Mimo rozsah

Žádné další oblasti zatím nebyly výslovně vyloučeny.
